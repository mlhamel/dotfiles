# oc-tokens run 2026-11-11

SSSM context-cap verification (TODOs P3). Commit `6ab705a` set
`limit.context` 65536 / `keep.tokens` 16384 on all six models; config
switch landed ~22:47 UTC and this run executed ~6h post-switch. HEAD
`27747c0`, master, unpushed.

## Method

1. `opencode/bin/oc-tokens`, full history plus `--days 1`.
2. Read-only sqlite on `~/.local/share/opencode/opencode.db`. Compaction
   events are `session_message` rows with `type='compaction'` (v2
   tables); `status`, `reason` and `tokens` live inside the JSON `data`
   column; join sessions on `session_v2.id`, not `session_id`. Trigger
   context = `tokens.input + tokens.cache.read` (input alone is only the
   uncached delta).

## Findings

| Regime                     | Completed auto-compactions | Trigger ctx (input + cache.read)                        | Designed trigger      |
| -------------------------- | -------------------------- | ------------------------------------------------------- | --------------------- |
| Old: cap 16384, keep 4096  | 208 in ~18h                | med 12,267; p25 11,552; p75 14,198; max outlier 240,986 | 12,288 (16384 × 0.75) |
| New: cap 65536, keep 16384 | 1 in ~6h                   | 37,808 (single event)                                   | 49,152 (65536 × 0.75) |

- Trigger math validated under the old cap: the median sits ~20 tokens
  from the designed value, so the same formula should fire at ~49,152 now.
- Old regime thrashed on active sessions: plan agent 85 events / 85
  turns; build-flashes 59/207, 25/167, 25/66.
- Post-switch: one completed auto-compaction (glm-5.3-flash:cloud,
  background-task-log session) at 37,808 ctx — ~11,344 short of 49,152.
  Consistent with an ~11k pending item pushing the window past the
  trigger; the recorded number is the summarizer call's own context.
- Four `compaction.interrupted` failed rows are session shutdowns, not
  config errors.
- Verdict: raise behaves as designed, thrashing gone. Post-switch sample
  is n=1 — too tiny to pin the exact 49,152 constant from the DB alone.
- Full-history context for scale: 251 sessions, 208.0M input / 11.8M
  output / 1.89B cache-read; top growth suspect a build session at 73.0M
  input over 507 msgs.
