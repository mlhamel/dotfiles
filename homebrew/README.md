# Homebrew

macOS-only package management via [Homebrew](https://brew.sh).

## Files

| File                 | Purpose                                                                   |
| -------------------- | ------------------------------------------------------------------------- |
| `Brewfile`           | Declarative list of taps, formulae (`brew`) and casks (`cask`) to install |
| `Brewfile.lock.json` | Pinned revisions/versions, regenerated by `brew bundle`                   |

## Setup (fresh Mac)

`setup.sh` (repo root) runs `brew bundle` on this Brewfile as its
packages step. Homebrew itself is the only prerequisite — if it is
missing, `setup.sh` prints the install command and continues with a
warning, so the rest of the bootstrap still runs.

Install Homebrew manually when needed:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

The Rake flow below remains as a manual alternative; it needs Ruby with
Bundler (`brew install ruby && gem install bundler`), which `setup.sh`
does not require.

```bash
cd ~/dotfiles
bundle install
rake   # = rake homebrew:install → brew bundle install
```

`Brewfile.lock.json` is regenerated by `brew bundle` on the first run;
the copy previously committed here predated Homebrew 4 (macOS Monterey, 2022) and was removed rather than refreshed by hand.

## Updating

After installing or removing packages on your machine, refresh the Brewfile:

```bash
rake homebrew:update   # from the repo root; = brew bundle dump --force
```

## Notes

- This section of the dotfiles is **macOS-only**; Homebrew on Linux does not
  support casks (Docker, Firefox, iTerm2, Spotify, VS Code, Zeplin are all
  casks) and is not the intended target.
- The `opencode/` part of these dotfiles is independent and works on any
  Linux/macOS machine — see the [repo README](../README.md).
