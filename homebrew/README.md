# Homebrew

macOS-only package management via [Homebrew](https://brew.sh).

## Files

| File                 | Purpose                                                                   |
| -------------------- | ------------------------------------------------------------------------- |
| `Brewfile`           | Declarative list of taps, formulae (`brew`) and casks (`cask`) to install |
| `Brewfile.lock.json` | Pinned revisions/versions, regenerated by `brew bundle`                   |

## Setup (fresh Mac)

1. Install Homebrew:

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. Install Ruby with Bundler (required by the Rake tasks; Homebrew's Ruby
   does not include bundler by default):

   ```bash
   brew install ruby
   gem install bundler
   ```

3. From the repo root:

   ```bash
   bundle install
   rake   # = brew bundle install (installs everything in the Brewfile)
   ```

## Updating

After installing or removing packages on your machine, refresh the Brewfile:

```bash
rake homebrew:update   # from the repo root; = brew bundle dump --force
```

## Notes

- This section of the dotfiles is **macOS-only**; Homebrew on Linux does not
  support casks (Docker, Firefox, iTerm2, Spotify, VS Code, Zeplin are all
  casks) and is not the intended target.
- The `opencode/` part of these dotfiles is independent and works on any
  Linux/macOS machine — see the [repo README](../README.md).
